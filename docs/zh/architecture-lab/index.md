# 架构实验室

架构实验室是整套文档里最偏实现视角的一段。它补充学院路线，直接点名贡献者需要遵守的模块边界、公共导出与运行时契约。

## 在这里该看什么

- [模块地图](./module-map) —— 仓库结构的实际分层；
- [运行时契约](./runtime-contracts) —— validation 与错误模型；
- 公共导出与私有 Triton 实现之间的分界。

这里关注的关键词是：模块地图、运行时契约、公共导出、validation。

## 为什么需要这一节

一个 kernel 库表面上可以很小，但内部仍可能藏着脆弱耦合。这里的目标正相反：展示公共导出保持克制、validation 被集中管理、周边支撑代码在解释运行路径，而不是掩盖它。

## 阅读建议

第一次进入代码库时先看模块地图；如果你正在补丁一个现有 Kernel family，或准备新增 family，需要明确 launcher 可以假设什么，就直接跳到运行时契约。
